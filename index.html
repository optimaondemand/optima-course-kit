Find a course first.

Module cards (edit titles, untick to hide)
Commonplace Corner, optional

4 Download and import

One file. Your home page is already inside it, set as the course front page, with the module cards linked to the real modules.
  1. In your Canvas course: Settings → Import Course Content.
  2. Content Type: Common Cartridge 1.x Package. Choose the file you just downloaded.
  3. Content: All content. Leave dates unadjusted. Click Import and wait for the green check.
  4. Open Home. Your page should be there with your name on it. If not: Pages → set it as Front Page → Home → Choose Home Page → Pages Front Page.
  5. Check Modules (count matches the kit) and Assignments (group weights present), then Publish the course.
Importing the same kit again later updates the course in place instead of duplicating it.
