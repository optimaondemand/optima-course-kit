6 Download and import

One file. Your home page is already inside it, set as the course front page, with the module cards linked to the real modules.
  1. In your Canvas course: Settings → Import Course Content.
  2. Content Type: Canvas Course Export Package. Choose the file you just downloaded.
  3. Content: All content. Leave dates unadjusted. Leave Import existing quizzes as New Quizzes unchecked: that option drops the module Intro and Outro surveys and hands you empty quizzes.
  4. Click Import and wait for the green check.
  5. Open Home. Your page should be there with your name on it. If not: Pages → set it as Front Page → Home → Choose Home Page → Pages Front Page.
  6. Check Modules (count matches the kit) and Assignments (group weights present), then Publish the course.
Importing the same kit again later updates the course in place instead of duplicating it.
